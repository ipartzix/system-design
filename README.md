# System Design

A structured engineering learning repository covering Low-Level Design (LLD), High-Level Design (HLD), and Machine Learning System Design, with Python implementations and practical case studies.

## Learning Areas

### 1. Low-Level Design (LLD)
- Object-Oriented Programming (OOP)
- UML Class Diagrams
- SOLID Principles
- Design Patterns
- Practical LLD Case Studies

### 2. High-Level Design (HLD)
- System Design Fundamentals
- Scalability
- Load Balancing
- Caching
- Database Architecture
- Distributed Systems

### 3. Machine Learning System Design
- ML System Architecture
- Data Pipelines
- Feature Stores
- Model Serving
- Model Monitoring

## Projects

Practical implementations and end-to-end system design case studies.

## Technology

- Python
- FastAPI
- PostgreSQL
- Redis
- Docker
- Distributed Systems
- Machine Learning Infrastructure

Technologies will be introduced progressively as the learning journey advances.

## Learning Philosophy

- Understand concepts before implementing them.
- Prefer practical implementations over memorization.
- Document architectural decisions and trade-offs.
- Build maintainable and scalable systems.
- Focus on engineering principles applicable to production environments.
